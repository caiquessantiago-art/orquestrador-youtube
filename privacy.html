Privacy Policy

Orquestrador The Fragile Human · Last updated: November 12, 2026

Orquestrador The Fragile Human ("the tool") is a private tool used only by the owner of the YouTube channel The Fragile Human. It runs on the owner's own Windows computer. It has no other users and no server of its own.

YouTube API Services

The tool uses the YouTube API Services. Use of the tool is subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

  • Basic information about the owner's own channel (channel ID and title), used to confirm that the tool is connected to the right channel.
  • The owner's own videos: the tool uploads them, sets their title, description, tags, thumbnail and publishing schedule, and reads their status.
  • Aggregated performance metrics of the owner's own channel and videos (for example views, watch time, impressions, click-through rate and audience retention), from the YouTube Analytics API and the YouTube Reporting API.

The tool does not access comments, messages, subscriber lists or any personal data of viewers, and it does not access any channel other than the owner's.

How the data is used

  • To upload and schedule the owner's videos.
  • To produce a weekly summary of the channel's numbers with suggestions for the next videos. This summary contains only aggregated numbers. It is generated with the owner's own AI assistant account (Claude, by Anthropic) and is read only by the owner.

Where the data is stored

  • The OAuth access authorization (refresh token) is stored only in the Windows Credential Manager of the owner's computer. It is never written to a file, a log or a code repository.
  • Aggregated metrics and the list of uploaded videos are stored as local files on the owner's computer. The metrics are collected again from the YouTube API Services every day, and the owner can delete these files at any time.

Sharing

The tool does not sell, share or show YouTube data to anyone other than the owner. The only exception is the weekly summary of aggregated numbers described above, which is processed by the owner's own AI assistant account to write suggestions for the owner.

How to revoke access

The owner can revoke the tool's access at any time on the Google security settings page: security.google.com/settings/security/permissions. After revocation, the tool stops working until it is authorized again, and the stored token can be removed from the Windows Credential Manager.

Contact

Questions about this policy: open an issue at github.com/caiquessantiago-art/orquestrador-youtube/issues.
